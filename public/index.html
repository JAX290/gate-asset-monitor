推送历史

在 VPS 上启用日报

① 在企业微信群添加「群机器人」，复制它的 Webhook 地址。
② 只把地址写进服务端 .env（不要发到对话里）：
WECOM_WEBHOOK_URL=https://qyapi.weixin.qq.com/cgi-bin/webhook/send?key=xxxx
REPORT_ENABLED=true
REPORT_HOUR=9          # 每天 9 点（UTC+8）
REPORT_TZ_OFFSET_HOURS=8
REPORT_PRESET=24H
# WECOM_MENTION_MOBILES=13800000000   # 可选 @人
sudo systemctl restart gate-asset-monitor
③ 也可完全用 CLI + cron：node deploy/daily-report.js --send。
未配置 webhook 时，日报仍会生成并预览 / 存档，只是不推送。

给第三方分析的约定

时间统一 UTC：ts_ms(Unix 毫秒) + ts_iso_utc(ISO 8601)
金额单位 USD；*_pct 为 0–100 百分数；ratio 类为小数
CSV 为 UTF-8 BOM + CRLF，Excel / pandas 直接可读
JSONL 每行一个对象：pd.read_json(path, lines=True)
空值表示不可计算或缺失，不代表 0
归因恒等式：Σ delta_value_usd + __RESIDUAL__ = 总资产变动
比较策略表现请用 nav.twr，不要用含现金流的总资产涨幅
